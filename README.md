# TACHKILA-V2
Le club amateur Atlas FC utilise déjà Tachkila pour préparer ses compositions en 4-4-2. L'entraîneur veut maintenant gérer son effectif et suivre ses matchs dans la même application.
Vous faites évoluer votre Tachkila v1 en trois pages réalisées en HTML, Tailwind CSS et JavaScript, qui partagent les mêmes données : Effectif (index.html), Composition (composition.html, la page de la v1) et Matchs (matchs.html).
Comprendre le métier : un joueur blessé ne peut pas jouer, l'équipe n'a qu'un capitaine et l'effectif compte au plus deux gardiens. Après chaque match, l'entraîneur note le score, qui donne le résultat : victoire, nul ou défaite.

## Technologies
- HTML5 sémantique
- CSS3 : CSS Grid
- Tailwind CSS
- JavaScript (DOM)
- Git et GitHub (branches, Pull Requests)
- Atlassian Jira (planification)
